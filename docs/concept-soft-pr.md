# 「やわらかいPR」コンセプト

「広報が楽しくなるような機能をつける」という方針のもとで出た、プレスリリースを軟らかく（人間味を持って）伝えるためのアイデアメモ。

## アイデア一覧

タブ切り替え等で見せる案として、以下のアイデアが挙がっている。

- 広報担当のメモ（制作秘話のようなもの）
- 後進育成
- リクルーティング
- 同業の人の頑張りを知る
- インライン編集（エディタ）
- 赤ペン先生的な添削
- 後で振り返る機能
- 勝手に提案
- メモの履歴
- ライト版（仮称）をブラウジングできるように
- 企業のサジェスト（同業他社はどうかな）
- 画像で見せたい
- 0→1に必要な情報
- 発信する前の情報収集
- 同業他社がどうやっているか
- メッセージボックス的な機能
- 交流会（ほかの広報担当と）
- 交流のある企業のカレンダー
- 他企業の状況の把握
- 仲間がいるという意識
- 社会に生きているという自覚

## リリースページへの適用方針

上記のうち、まずリリース詳細ページに実装するのは以下の内容。

- 「やわらかいPR」として、公式リリースの本文に広報担当のコメントを添えて見られるようにする
- 表示・非表示の切り替え（`?mode=soft` のようなクエリパラメータ、タブまたはトグル）
- 本文中のハイライト部分にマウスオーバーすると、広報担当のコメントが吹き出しで展開
- 本文の下に、そのリリースについての広報担当コメント欄を設ける

参考デザイン: Claude Design の「Press Release Soft v3」

## 現状の実装範囲

フロントエンドのみ（データはモック）で、以下を実装済み。

- リリース詳細ページに「やわらかいPR」の追加情報表示を実装（`components/ArticlePage.tsx` ほか）
- 本文ハイライト部分のホバーで広報担当コメントを表示（`components/AnnotatedContent.tsx`）
- 広報担当コメントへの画像添付
- 対応データを持つ記事（あんどこどもクリニックの開院リリース）のみが「やわらかいPR」の内容を持ち、データの無い記事は通常表示にフォールバックする

## 未着手・今後の検討事項

以下は今回のスコープ外で、コンセプトメモの段階に留まっている。

- 後進育成・リクルーティング向けコンテンツ
- 同業他社のサジェスト、交流会、企業カレンダーなどのコミュニティ機能
- インライン編集（エディタ）、赤ペン先生的な添削、メモの履歴管理
- これらはバックエンド・データ永続化を前提とするものが多く、実装時は別途設計が必要
